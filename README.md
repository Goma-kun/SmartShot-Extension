# SmartShot（Chrome拡張版）

範囲選択スクリーンショットのChrome拡張機能です。ホバーするだけでページ内の要素を自動検出し、ドラッグでの手動選択やハンドルでの微調整もできます。確定した瞬間にPNG保存とクリップボードコピーが同時に行われるので、撮ってすぐ⌘Vで貼り付けられます。

macOSアプリ版（Python + PyQt6、画面全体・ウィンドウキャプチャ・録画対応）の姉妹プロジェクトとして、ブラウザ内のキャプチャを担当します。

## 機能

- **⌥⇧S** でオーバーレイ起動（ツールバーのアイコンからも起動可能）
- ホバーで要素を自動検出してそのままキャプチャ
- ドラッグで手動範囲選択
- 選択後はハンドルでリサイズ・移動して微調整
- 実ピクセル数のサイズバッジ表示（Retina対応）
- 確定と同時にPNGをダウンロード＋クリップボードへ自動コピー
- **Esc** で再選択／キャンセル、**Return** または枠内クリックで確定

## インストール

Chrome Web Storeには未公開のため、デベロッパーモードで読み込みます。

1. このリポジトリをクローンまたはZIPでダウンロード
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をON
4. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択

## 使い方

1. キャプチャしたいページで **⌥⇧S** を押す
2. 画面が暗転したら、撮りたい要素にホバー（自動検出）するか、ドラッグで範囲を選択
3. クリックで選択を確定するとプレビューになり、ハンドルで調整できる
4. **Return** か枠内クリックで保存 — PNGがダウンロードされ、クリップボードにもコピーされる

## 制限事項

- Chrome APIの仕様上、キャプチャできるのは表示中のタブの領域のみです。画面全体や他アプリのウィンドウはmacOSアプリ版をお使いください。
- `chrome://` などの特殊ページでは動作しません。
